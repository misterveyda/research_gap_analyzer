# research_gap_analyzer
Automated Literature Review Research Gap Finder 

Problem it solves:
Students waste weeks manually reading papers to identify research gaps.

A tool that:

Takes a research topic

Fetches papers (PDFs)

Extracts abstracts

Clusters topics

Highlights under-researched areas

Tech stack:

Python

NLP (spaCy / NLTK)

TF-IDF / LDA

Streamlit (UI)
